2. Datos que recogemos

Cuando visitas este sitio web, se recoge la siguiente información mediante el script de analítica privada alojado en Cloudflare Workers :

  • Dirección IP
  • Navegador y sistema operativo (extraídos del User-Agent)
  • URL de la página visitada
  • Fecha y hora de la visita / última actividad
  • Identificador de sesión generado a partir de un hash (SHA-256 de app_id + IP + User-Agent)

No se recogen nombres, correos electrónicos, datos de formularios ni ninguna otra información identificativa directa, salvo que el usuario la facilite voluntariamente a través de formularios de contacto u otros medios.

3. Finalidad del tratamiento

Los datos se tratan exclusivamente con las siguientes finalidades:

  • Elaborar estadísticas de uso del sitio web (número de visitas, páginas más vistas, navegadores, sistemas operativos y países de origen).
  • Detectar y prevenir abusos o usos indebidos.
  • Mejorar el funcionamiento y la experiencia del sitio.

No se utilizan con fines publicitarios ni se venden a terceros.

4. Base legal

El tratamiento se basa en el interés legítimo del responsable (artículo 6.1.f del RGPD) para conocer el uso de su sitio web y mejorar el servicio, siempre que no prevalezcan los derechos e intereses del interesado.

Si en el futuro se implementara un banner de cookies o se solicitara consentimiento explícito, se indicará en esta política.

5. Conservación de los datos

Los datos de visitas se conservan durante el tiempo necesario para cumplir las finalidades descritas y, como máximo, 24 meses desde la última actividad registrada. Transcurrido ese plazo se eliminan o se anonimizan de forma irreversible.

6. Destinatarios y encargados del tratamiento

Los datos se almacenan y procesan en la infraestructura de Cloudflare, Inc. (Workers y base de datos D1), que actúa como encargado del tratamiento.

Cloudflare cuenta con las garantías adecuadas conforme al RGPD (incluidas Cláusulas Contractuales Tipo y medidas de seguridad técnicas y organizativas).

No se ceden datos a otros terceros, salvo obligación legal.

7. Transferencias internacionales

Cloudflare tiene servidores en Estados Unidos y en otros países. Las transferencias se realizan con las garantías previstas en el RGPD (Cláusulas Contractuales Tipo de la Comisión Europea y demás medidas complementarias).

8. Derechos de los interesados

Puedes ejercer en cualquier momento los siguientes derechos:

  • Acceso
  • Rectificación
  • Supresión (“derecho al olvido”)
  • Limitación del tratamiento
  • Oposición
  • Portabilidad

Para ejercerlos, envía un correo a blog.cottage627@passinbox.com indicando el derecho que deseas ejercer y aportando la información necesaria para localizar tus datos (por ejemplo, la dirección IP o el periodo aproximado de la visita).

También tienes derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es (se abre en una pestaña nueva)).

9. Cookies y tecnologías similares

Este sitio utiliza un script de seguimiento propio que se carga desde el dominio del panel de analítica. Este script no instala cookies de terceros ni realiza seguimiento publicitario.

Si el navegador tiene activado el bloqueo de scripts o se utiliza una extensión de privacidad, el seguimiento puede no ejecutarse.

10. Seguridad

Se aplican medidas técnicas y organizativas adecuadas para proteger los datos contra el acceso no autorizado, la pérdida o la alteración (incluyendo el uso de API keys de alta entropía, sentencias preparadas, rate limiting y cabeceras de seguridad).

11. Cambios en la política

Nos reservamos el derecho a modificar esta Política de Privacidad para adaptarla a cambios legislativos o de funcionamiento. La versión actualizada se publicará en esta misma página con la fecha de la última revisión.
